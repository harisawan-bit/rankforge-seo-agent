# RankForge SEO For Antigravity

Use this file as the project-level SEO operating guide.

## Activation

Use RankForge SEO whenever the user asks to:

- Audit a site or page
- Improve rankings
- Recover traffic
- Improve technical SEO
- Optimize content
- Improve internal linking
- Add or fix schema
- Build a local SEO plan
- Build an ecommerce SEO plan
- Plan programmatic SEO
- Improve AI visibility, GEO, or AEO
- Build an SEO reporting plan

## Operating Flow

1. Confirm the target if it is missing.
2. Identify target type and business model.
3. Collect shared evidence once.
4. Audit technical SEO, indexation, performance, UX, on-page SEO, content quality, architecture, links, schema, entity clarity, AI visibility, and measurement.
5. Run local, ecommerce, programmatic, and authority branches only when relevant.
6. Prioritize by search impact, business impact, effort, and confidence.
7. End with personalized human-only off-page SEO recommendations: things the user must personally do, such as relationship outreach, reviews, partnerships, local citations, PR, events, sponsorships, and expert-source opportunities.
8. Produce a concise action plan or full report based on the user request.

## Finding Format

Use this format for major findings:

```text
Finding:
Evidence:
Impact:
Fix:
Priority:
Confidence:
```

Confidence must be one of:

- Confirmed
- Likely
- Hypothesis

## Roadmap Buckets

- Quick wins: 0 to 7 days
- High-impact fixes: 1 to 4 weeks
- Strategic plays: 30 to 90 days
- Monitoring: recurring checks and alerts

## Human-Only Off-Page SEO

Always include personalized recommendations for off-page work an AI assistant can plan or draft but cannot actually complete without the user.

For each item, include:

- Why this fits the specific business
- What the person must do manually
- What the AI assistant can prepare
- Expected SEO or trust impact
- Difficulty
- Time horizon
- First next step

## Guardrails

- Use measured evidence when available.
- State limitations when a check cannot be measured.
- Avoid vague recommendations.
- Avoid spam tactics.
- Keep recommendations useful for humans and understandable for search and AI systems.
